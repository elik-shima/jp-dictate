JP Dictate

fn を押している間だけ話すと、離したときにカーソルの位置へ日本語が入力されます。認識はすべて Mac の中で行います。

インストール

必要なもの: macOS 26 以降、Apple シリコン (M1 以降) の Mac。

  1. 受け取った JP Dictate.app を「アプリケーション」フォルダに入れます。zip で受け取った場合は、ダブルクリックで展開してから移動してください。
  2. JP Dictate.app をダブルクリックします。「開発元を確認できないため開けません」と表示されたら「完了」を押して閉じ、 システム設定 → プライバシーとセキュリティ の下のほうにある「“JP Dictate”はブロックされました」の横の 「このまま開く」 を押します。
  3. メニューバーの右上に波形のアイコンが出れば起動しています。Dock には表示されません。
このアプリは Apple の公証を受けていないため、最初の 1 回だけ上の操作が必要です。2 回目からは普通に開けます。

はじめての設定

起動すると、許可を求める画面が順に出ます。システム設定 → プライバシーとセキュリティ で、次の 3 つすべてに「JP Dictate」を許可してください。

項目何に使うか
入力監視fn キーを押したこと・離したことを知るため。文字の入力内容は記録しません
アクセシビリティ認識した文章をカーソルの位置に貼り付けるため (⌘V を送ります)
マイクfn を押している間の声を録るため

許可したら、JP Dictate の画面の 「再起動」 を押します (またはメニューバーのアイコン →「再起動」)。

録音キーを選ぶ

最初は fn で録音します。Apple 製以外のキーボード (Logicool・Keychron など) では、 fn がキーボードの中で処理されて Mac に届かず、反応しないことがよくあります。その場合は、 メニューバーのアイコン →「録音キー」で、右側の修飾キーに切り替えてください。

録音キー向いているキーボード
fn (🌐)Mac 本体・Apple 製のキーボード
右 ⌥ optionApple 製以外のキーボードも含め、ほとんどのキーボード (おすすめ)
右 ⌘ command同上
右 ⌃ control同上 (右側に control があるキーボードのみ)

右側のキーを選ぶと、左側の同じキーは今までどおり使えます。選んだキーは次回の起動でも使われます。 以下の説明の fn は、選んだ録音キーに読み替えてください。

🌐キーの設定 (fn を使う場合)

システム設定 → キーボード の「🌐キーを押して」を 「何もしない」 にしてください。 ほかの動作 (絵文字と記号の表示・入力ソースの変更・音声入力の開始) になっていると、fn を押すたびにそれも一緒に動いてしまいます。

清書モードを使う (任意)

録音キーを Shift と一緒に押して話すと、認識した文章を Anthropic の Claude (Claude Haiku 5.5) で整えてから入力します。 整えるのは、句読点・「えーと」などの言いよどみと言い直し・前後の文脈から明らかな 1〜2 文字の誤字の 3 つだけで、語尾や言い回しは変えません。

使うには、メニューバーのアイコン →「清書モード」→「API キーを設定…」で、Anthropic の API キーを入れます。キーはこの Mac のキーチェーンに保存されます。 清書には 1〜2 秒ほどかかります。うまく整えられなかったとき (通信できない・時間切れなど) は、認識した文章をそのまま入力します。

ログイン時に自動で起動する

メニューバーのアイコン →「ログイン時に起動」にチェックを入れます。

使い方

  1. fn を押したまま「ティン」と鳴ったら録音が始まります。
  2. 話す句読点は自動で付きます。何文か続けて話しても大丈夫です。
  3. 離す「ポン」と鳴り、0.1 秒ほどでカーソルの位置に入力されます (清書モードでは 1〜2 秒)。
  • 押してから一呼吸おいて話すと、最初の言葉が欠けません (押した瞬間にマイクを開くため、ごく短い間だけ録音が始まっていません)。
  • 清書モード: Shift を押しながら fn を押して話すと、整えてから入力します (「はじめての設定」の清書モードを参照)。録音中に Shift を離しても取り消しにはなりません。
  • 取り消したいとき: fn を押したまま、ほかのキーを押します。その回は何も入力されません。 fn＋← などのショートカットを使ったときも、自動で取り消しになります。
  • ごく短く押しただけのとき (0.2 秒未満) や、何も話さなかったときは何もしません。
  • 1 回に話せるのは 120 秒までです。それを超えると自動で録音を止めて入力します。

表示状態

アイコンをクリックすると、最後に入力した文章と所要時間、「録音キー」「清書モード」「再起動」「ログを表示」「プライバシー設定を開く」「ログイン時に起動」「終了」が選べます。

入力のしくみ

文章はクリップボードを経由して貼り付けます。そのため、次のように動きます。

  • クリップボードは元に戻ります。 貼り付けの 1.5 秒後に、それまでコピーしていた内容 (画像なども含む) に戻します。その間に別のものをコピーした場合は、そちらを優先して戻しません。
  • パスワード入力欄には入力しません。 パスワードの欄にカーソルがあるときは、認識しても貼り付けません。
  • 話している間にアプリが切り替わったら、貼り付けません。 文章はクリップボードに入れておくので、目的の場所で ⌘V を押してください。
  • パスワード管理アプリでコピーした内容は戻しません。 自動で消える設定を無効にしないためです。

プライバシー

  • 音声の認識は、すべてこの Mac の中で行います。音声は外部に送りません。
  • 文章も外部に送りません。例外は清書モード (Shift と一緒に押したとき) で、そのときだけ認識した文章を Anthropic の Claude API に送ります。
  • マイクは fn を押している間だけ開きます。録音はメモリの中だけで扱い、ファイルに保存しません。
  • ログ (~/Library/Logs/JPDictate/dictate.log) には、動作の記録と文字数だけを書き、認識した文章は書きません。
  • 貼り付けに使う文章は、この Mac のクリップボードだけに置きます。ほかの Apple 製品と共有されるユニバーサルクリップボードには送りません。

困ったとき

fn を押しても反応しない

「入力監視」と「アクセシビリティ」が許可されているか確認してください。一覧でオンになっていても効いていない場合は、 その項目の「JP Dictate」を選んで「−」で削除し、JP Dictate を開き直して許可し直します。ターミナルで次を実行してから開き直しても同じです。

tccutil reset ListenEvent local.jp-dictate; tccutil reset Accessibility local.jp-dictate; tccutil reset PostEvent local.jp-dictate

Apple 製以外のキーボードでは、fn キーがキーボード内部で処理されて Mac に届かないことがあります。 その場合は、メニューバーのアイコン →「録音キー」で 右 ⌥ などに切り替えてください。

録音はされるが、文章が入力されない

「アクセシビリティ」の許可を確認してください。パスワード入力欄や、話している間に別のアプリに切り替えた場合は、仕様として貼り付けません (メニューバーのアイコンをクリックすると理由が表示されます)。

声を拾わない・「マイクの音声が届いていません」と出る

「マイク」の許可を確認してください。システム設定 → サウンド → 入力 で、使いたいマイクが選ばれているかも確認します。 AirPods などの Bluetooth のマイクは、使い始めるまでに少し時間がかかるため、押してから一呼吸おいて話してください。

最初の言葉が欠ける

fn を押してから一呼吸おいて話し始めてください。押した瞬間にマイクを開くため、ごく短い間は録音が始まっていません。

fn を押すと絵文字パネルなどが一緒に開く

システム設定 → キーボード の「🌐キーを押して」を「何もしない」にしてください。

macOS 標準の音声入力との違いは？

どちらも macOS の音声認識を使いますが、標準の音声入力は話しながら少しずつ文字にする方式で、黙ると自動で止まります。 JP Dictate は押している間の発話をまとめて認識するため、言葉を取りこぼしにくく、句読点も付きやすくなります。

アンインストール

  1. メニューバーのアイコン →「ログイン時に起動」のチェックを外し、「JP Dictate を終了」を選びます。
  2. 「アプリケーション」フォルダの JP Dictate.app をゴミ箱に入れます。
  3. システム設定 → プライバシーとセキュリティ の「入力監視」「アクセシビリティ」「マイク」から「JP Dictate」を「−」で削除します。
  4. 記録も消す場合は、~/Library/Logs/JPDictate と ~/Library/Application Support/JPDictate のフォルダを削除します。
